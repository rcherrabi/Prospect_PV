# Prospect_PV
Outil PyQGIS d'ingénierie spatiale automatisant la prospection solaire départementale. Il croise cadastre, pente, réseaux et enjeux écologiques pour détecter en quelques heures les parcelles à fort potentiel (Agri-PV, PV au sol, foncier public), réduisant les délais de plusieurs jours à 1-8 h.
